# فراخ البيت

متابعة فراخ البيت عند عبد الرحمن: الدورة، المصاريف، البيع، الديون، المخزون، والسعر. الاستعمال شخصي، من غير كلمة سر.

## التشغيل

```bash
npm run dev
```

ثم افتح `http://localhost:3000`. الصفحة الرئيسية تفتح مباشرة.

قاعدة البيانات المحلية الخاصة بالمشروع تعمل على المنفذ `5434`، وبيانات الاتصال في `.env.local` ولا تُرفع مع الكود.

لو احتجت تعيد إنشاء الجداول:

```bash
npm run db:migrate
```

## السوق

الأسعار إدخال يدوي. لا يوجد مصدر رسمي لحظي موثوق لسعر الدواجن في مصر. التفاصيل في `docs/MARKET-SOURCES.md`.
